## 📌 Overview

**Track Journey** is a React-based UI project built to practice essential frontend concepts such as:

* List Rendering
* Event Handling
* Conditional Rendering
* useState Hook

It showcases train data in a clean, responsive card layout with interactive UI elements.

---

## ✨ Features

* 🚆 Dynamic Train Listing
* 📱 Responsive Navbar with Mobile Toggle
* 🔄 Availability Status (Conditional Rendering)
* 🖱️ Interactive Button Events
* ⚛️ State Management using `useState`
* 🎨 Styled with Tailwind CSS
* 🧩 Reusable Components

## 📚 Concepts Covered

### 🔹 List Rendering

Using `.map()` to render train and navbar data.

### 🔹 Event Handling

* Toggle mobile menu
* Add train to journey (alert)

### 🔹 Conditional Rendering

Display:

* 🟢 Available
* 🔴 Unavailable

### 🔹 useState Hook

Control navbar toggle state.
